# 신민근 포트폴리오

빌드 없이 동작하는 HTML/CSS/JavaScript 사이트입니다.

| 지원 직무 | 페이지 |
| --- | --- |
| 영업기획·관리 | `index.html` |
| 마케팅 | `marketing/index.html` |
| 데이터 분석 | `data/index.html` |

소개 → 프로젝트 → 경험과 직무 연결 → 이력 → 연락 순서입니다. 마케팅은 모집 캠페인을, 데이터 분석은 분석 사례를 먼저 보여 줍니다.

## 로컬 확인

이 디렉터리에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 엽니다. 모바일 상단 탐색은 가로로 스크롤할 수 있습니다. JavaScript가 꺼져도 본문과 링크가 표시됩니다.

## 수정 기준

- 운영 근거: 상위 `나` 폴더의 마케팅 성과 정리와 본인 이력.
- 분석 근거: 상위 `데이터분석 포트폴리오` 폴더의 마스터 문서 3종.
- 광고주 16개사·25건은 무료 게재 포함입니다. 평균 1.6건은 최초 집행을 포함하며 재계약률이 아닙니다.
- 광고비 80만 원÷전체 모집 1,021명≈784원은 유료 채널별 고객 획득 비용이 아닙니다.
- 관측 차이·실험 설계·실현된 개선 성과를 구분합니다.
- 개인 문서와 원문 전체는 공개 저장소에 복사하지 않습니다.

`assets`와 `projects`는 세 경로에 사본이 있습니다. 공통 스타일과 수치 교정은 모든 경로에 반영합니다. 단, `marketing/projects/lms-ad-sales.html`과 `recruit-content.html`은 마케팅 전용 사례를 더해 별도로 유지하므로 전체 파일을 덮어쓰지 않습니다. 홈의 직무별 문구·순서도 따로 유지합니다.
