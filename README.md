# 신민근 포트폴리오

정적 웹사이트입니다. 빌드 도구나 설치 과정이 없고, `index.html`을 브라우저로 열면 그대로 동작합니다.

배포 주소: https://mingeun-git.github.io/

## 파일 구조

```
.
├─ index.html                     홈. 소개 · 강점 · 핵심 역량 · 프로젝트 목록 · 이력
├─ projects/
│  ├─ lms-ad-sales.html           LMS 광고 지면 사업화
│  ├─ etacrew.html                대학 커뮤니티 홍보단 확대
│  ├─ recruit-content.html        학회원 모집 콘텐츠와 예산 운용
│  ├─ dayton-superb.html          두 행사의 채널 분석과 회고
│  └─ retention.html              구독 플랜 리텐션 분석
├─ assets/
│  ├─ css/
│  │  ├─ tokens.css               디자인 토큰. 색 · 타입 · 간격 · 모션
│  │  └─ main.css                 컴포넌트 스타일. 모든 페이지가 공유
│  └─ js/
│     └─ main.js                  스크롤 등장 효과, 현재 섹션 표시
└─ README.md
```

## 디자인 기준

**시스템** IBM Carbon Design System v11을 기반으로 합니다. 색상 팔레트는 `@carbon/colors` 원본 hex 값을, 타입 스케일과 간격은 `@carbon/type`과 Carbon spacing scale을 그대로 씁니다. 수치와 표가 많은 화면을 위해 만들어진 시스템이라 위계가 촘촘하고 회색 램프의 대비가 강합니다.

**의도적으로 바꾼 세 가지** `tokens.css` 상단 주석에 이유와 함께 적어 뒀습니다. 강조색을 IBM Blue 대신 Teal 70으로 바꾼 것, 한글 본문 행간을 넓힌 것, 다크 테마를 넣지 않은 것입니다.

**토큰** 원시값(`--c-`) → 의미(`--text-`, `--accent-`, `--border-`) → 컴포넌트(`--card-`, `--table-`)의 3계층입니다. `main.css`에서는 색 코드를 직접 쓰지 않고 항상 토큰을 거칩니다. 색을 바꾸려면 `tokens.css`의 원시 팔레트만 손대면 전체가 따라옵니다.

**그래프** 이미지 파일이나 차트 라이브러리를 쓰지 않습니다. 전부 HTML과 인라인 SVG로 그렸습니다.

**동작** 스크롤에 따라 내용이 한 번씩 드러나고, 프로젝트 타일은 마우스를 올리면 살짝 커집니다. 운영체제에서 동작 줄이기를 켠 사용자에게는 두 효과 모두 꺼집니다. 자바스크립트가 없거나 `main.js`가 로드되지 않아도 3초 뒤 모든 내용이 보이도록 안전장치를 넣었습니다.

## 아직 채워야 할 곳

홈 프로젝트 섹션의 `정리 중` 타일 두 개가 비어 있습니다. 데이터 분석 프로젝트 두 건을 넣을 자리입니다.

채우는 방법은 두 단계입니다.

1. `projects/` 안에 새 HTML 파일을 만듭니다. `retention.html`을 복사해 내용만 바꾸는 것이 가장 빠릅니다.
2. `index.html`에서 해당 `tile--pending` 블록을 `retention.html`을 가리키는 타일과 같은 형태로 바꿉니다.

## 상세 페이지의 구조

모든 프로젝트 상세 페이지가 같은 순서를 따릅니다.

| 블록 | 역할 |
| --- | --- |
| `detail-hero` | 제목, 한 문단 요약, 소속과 기간 등 사실 |
| `narrative` | 왼쪽에 상황 · 판단 · 실행 · 결과, 오른쪽에 그래프 |
| `vizfull` | 오른쪽 칼럼이 너무 길어질 때 마지막 그래프를 전체 폭으로 내리는 자리 |
| `takeaway` | 마지막 한 문단. 어두운 배경 |
| `pager` | 이전 · 다음 프로젝트 |

## 그래프 종류

| 클래스 | 쓰임 | 조절하는 값 |
| --- | --- | --- |
| `.bars` | 항목별 크기 비교 | `style="--w:70%"` |
| `.steps` | 단계별 축소. 퍼널 | 없음 |
| `.gauges` | 목표 대비 달성률 | `--w`와 목표선 `--at` |
| `.compare` | 전후 두 값 비교 | 없음 |
| `.stack` | 비중 배분 | 각 조각의 `--w` |
| `.dtable` | 수치 표 | 없음 |
| `.cutplot` | 분포와 커트라인 | SVG 좌표 |
| `.quad` | 산점도, 선 그래프 | SVG 좌표 |
